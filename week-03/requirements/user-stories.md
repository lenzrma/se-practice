# User stories — Smart Campus study room booking

6 to 8 stories, kept after review. Roles are Student or Administrator only.

---

### US-01
**Story:** As a Student, I want to view real-time room availability, so that I can find a free room for my study session.
**Priority:** High
**Assumption:** Availability is shown per room and time slot for the current and future dates only; slots that have already passed are not shown as available.

### US-02
**Story:** As a Student, I want to book a free room for a specific time slot, so that I can guarantee a place to study.
**Priority:** High
**Assumption:** The system checks R1–R3 (future start, max two hours, no overlap) before confirming; a student may hold more than one active booking at a time.

### US-03
**Story:** As a Student, I want to cancel a booking I made, so that I can free the room if my plans change.
**Priority:** Medium
**Assumption:** Only the student who made the booking can cancel it; a cancellation releases the slot immediately, and a booking that has already started can no longer be cancelled.

### US-04
**Story:** As an Administrator, I want to block or unblock a room, so that I can take it out of service when it is unusable and return it to use once it is ready.
**Priority:** High
**Assumption:** Blocking a room only prevents new bookings under R4; it does not cancel bookings that already exist for that room.

### US-05
**Story:** As an Administrator, I want to review how rooms were used over a period, so that I can see which rooms are over- or under-used.
**Priority:** Medium
**Assumption:** Usage figures are built from completed, cancelled and blocked-time records for the chosen period; the review does not need to be real-time.

### US-06
**Story:** As a Student, I want to receive a confirmation when my booking or cancellation succeeds, so that I know the system registered my action.
**Priority:** Medium
**Assumption:** The confirmation is generated by the system itself the moment a booking or cancellation is processed; no person requests it directly.
