# Comparison: Manual vs. AI-Generated Solution

| Metric / Aspect | Part 1: Manual Solution (`solution.py`) | Part 2: AI-Generated App (Rocket) |
| :--- | :--- | :--- |
| **Development Speed** | Took around 15–20 minutes to write logic, handle edge cases, and test via console. | Generated in less than 2 minutes via prompt and refinement. |
| **User Interface** | Command-line interface (CLI); text-based output, requires running python script manually. | Full-featured web GUI with interactive charts, sliders, badges, and export options. |
| **Handling Edge Cases** | Required explicit Python code (`try-except`, bounds checking `0-100`, filtering empty values). | Handled automatically by the AI framework with robust input parsing and visual error states. |
| **Effort & Complexity** | Moderate mental effort required for writing algorithms and string parsing. | Minimal effort; focused entirely on high-level feature requirements and UX. |
| **Extensibility** | Harder to scale into a full app without adding an external framework (like Flask or Streamlit). | Highly extensible, component-based, and ready for immediate deployment. |
